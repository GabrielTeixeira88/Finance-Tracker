# Group investment analytics under Insights

Finance Tracker currently exposes Performance twice and labels portfolio insights
as Allocation inside an oversized Investments tab row. Adopt the reference's
**Insights / Overview | Performance | Income** grouping, with composition and
exposure in Overview, preserving direct bookmarks and contextual links.
This trades an additional navigation step for a single analytical workspace and
clear separation from investment operations, without adding allocation targets.

Accepted for the redesign specification on 2026-10-26; implementation remains
subject to approval of the completed specification. This does not decide the
remaining sidebar or the detailed analytics layouts and calculations.
