# Unified Dashboard with Spending first

Finance Tracker's separate cash Overview, Investments overview and Net Worth
overview create overlapping destinations and impede the requested reference
hierarchy. Adopt one Dashboard with **Spending / Investments / Net Worth** modes,
preserving existing financial information and bookmarks; the user explicitly
chose Spending first instead of the reference's Investments-first ordering.
This trades familiarity with existing navigation for a coherent shared dashboard
while prioritizing everyday spending on first entry.

Accepted for the redesign specification on 2026-10-26; implementation is not yet
authorized. Q39 (2026-10-27) resolves repeat visits: the generic Dashboard button
opens Spending, while explicit mode bookmarks and browser Back restore their
intended destination. The remaining primary sidebar was confirmed separately in Q6.
