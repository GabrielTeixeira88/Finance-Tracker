# Use full-page details for durable financial entities

Finance Tracker currently mixes component-local detail views with large drawers,
limiting durable links and space for financial history and planning. Use
bookmarkable full pages within the persistent shell for account, holding, goal,
manual asset and liability details, accepting a page transition in exchange for
reference-like space and reliable navigation.

Preserve originating list filters and position on return. Drawers remain available
for quick edits and contextual drilldowns. Manual assets/liabilities were explicitly
added by interview decision Q24, with Open details links from category-summary
sheets. Life Events instead use the inline timeline/detail pattern agreed in Q17.
Q30 also establishes a bookmarkable full-page workspace per reconciliation
statement, replacing multiple expanded statement accordions without merging
statement completion with source matching or transaction review.

Accepted for the redesign specification on 2026-10-26; implementation awaits
approval of the completed specification. Preserve the application's hash-route
architecture and existing bookmarks when defining the eventual detail routes.
